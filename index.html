🔬 Technical Highlights

🧠 TrustRank Algorithm

PageRank variant using NetworkX with weighted edges (location: 0.5, taxonomy: 0.7, ZIP: 0.6). Converges in ~20-50 iterations with O(V+E) complexity.

💾 Semantic Memory

sentence-transformers (384-dim) + FAISS IndexFlatL2. Similarity = 1/(1+distance). Handles 100k+ memories with O(log N) search.

🔐 Security Stack

JWT (HS256) + TOTP 2FA + bcrypt passwords + AES-256 encryption + SHA3-256 hashing + RBAC + audit logging.

🌐 Free APIs

NPI Registry (CMS public API) + Nominatim (OSM, 1 req/sec cached). Zero API costs forever.

🤖 Agent System

Meta-agent orchestration, memory agents with FAISS, reinforcement learning via human feedback, episodic/semantic/procedural memory.

📊 Observability

Prometheus metrics, structured JSON logs (structlog), health probes, request tracking, error monitoring.

💡 Why This Tech Stack?

Decision Rationale
Nominatim over Google Maps $0 forever vs $200/month. OSM has excellent US coverage. Self-hostable.
NetworkX over Neo4j No separate database. Fast for <100k nodes. Zero licensing.
FAISS CPU over GPU No GPU = cheaper servers. Handles 100k vectors. Simpler deployment.
Local LLM (optional) No OpenAI/Anthropic fees. Data privacy. Full control.
FastAPI over Flask Native async. Auto-docs. Type hints. Production-ready.
PostgreSQL over MongoDB ACID guarantees. JSON support. Free forever. Mature tooling.
